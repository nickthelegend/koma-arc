# Judge walkthrough

Live: https://app-production-758c.up.railway.app (Arc testnet)

1. Browse Catalog and Series to see indexed live Arc testnet contracts.
2. Open Receipts for measured payment/mint transactions and honest cross-chain status.
3. Create a comic with a one-page order (0.10 testnet USDC) and an Arc wallet signature. AI generation requires the configured provider account to remain funded.
4. Open Writers' Room to create a passkey-protected encrypted draft; this requires your authenticator.
5. See [hosted checks and limitations](HOSTED.md) and `docs/screens/hosted/` for screenshots and the smoke-action receipt. The prior full testnet walkthrough is in [E2E-TESTNET.md](E2E-TESTNET.md).
